DOM Hydration v42.1.5
@keshavsoft/json-to-dom

Translates pure declarative JSON specifications into live native HTML DOM nodes and mounts them into the document target.

import jsonToDom from "@keshavsoft/json-to-dom";
const dom = jsonToDom({ jsonSpec: spec, targetHtmlId });

Event Delegation v1.1.1
json-renderers-build-table-events

Provides container-level event delegation (live search filtering, persistent input focus, row clicks, and footer saves) decoupled from the rendering engine.

import { hookTableEvents } from "json-renderers-build-table-events";
hookTableEvents({ container, dataset, columns, onSearch, onSave });
Docs Site → Repo
Validation v1.5.3
json-renderers-guard

Guards and validates incoming table configuration at runtime. Ensures data arrays, columns, and target IDs conform before attempting transformation.

import guardFunc from "json-renderers-guard";
guardFunc(config); // throws descriptive error if invalid
npm package → Repo
Instruction Engine v1.7.1
json-renderers-run-instructions

Iterates over declarative instruction blueprints (single, rowOnColumn, columnOnRow) and stamps records and columns into the template tree.

import runInstructions from "json-renderers-run-instructions";
runInstructions({ single, rowOnColumn, columnOnRow, base, data });
npm package → Repo
Dynamic Options v1.2.1
json-renderers-run-options

Applies dynamic options onto the stamped base specification (e.g., toggling serial numbers, adding action column options).

import runOptions from "json-renderers-run-options";
runOptions({ base, options, optionDefs, showLog });
