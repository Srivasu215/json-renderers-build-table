V55 Architecture & Pipeline
Pure Rendering + Delegated Events

V55 marks a major architectural milestone: removing legacy monolithic event attachments and DOM traversal from the core table renderer, isolating pure specification stamping from interactive container delegation.

Source Imports

What src/v55/index.js Imports

Every module imported in V55 serves a distinct, non-overlapping purpose.

Guard
json-renderers-guard

Validates configuration object, data array, column definitions, and target ID before running transformations.

Spec Builder
buildTableSpec.js

Composes spec-repo base specs, runs json-renderers-run-instructions, and applies json-renderers-run-options.

DOM Hydrator
@keshavsoft/json-to-dom

Hydrates declarative JSON specifications directly into DOM elements without intermediate string parsing.

Event Hook
json-renderers-build-table-events

Orchestrates event delegation (search, row selection, actions, footer save) independently from the rendering lifecycle.

The Clean V55 Architectural Shift
What Was Removed
  • No monolithic event bundling: Removed direct coupling to legacy event handlers.
  • No direct traversal logic: Traversal belongs to the event layer, keeping the table builder 100% pure.
  • No search focus destruction: The search input is outside the re-rendered table body, so typing never loses DOM focus.
What Was Preserved & Refined
  • Intact instruction engine: json-renderers-run-instructions remains untouched, stamping single, rowOnColumn, and columnOnRow arrays.
  • Clean Two-Phase API: render() for mounting structure; hookEvents() for wiring interactivity.
  • Universal Global Registration: Available as ES Modules and browser globals via window.JsonRenderers.buildTable.v55.

V55 Core Implementation Overview

Phase 1: Pure Table Rendering
// src/v55/index.js
const render = (config = {}) => {
    guardFunc(config);
    const spec = buildTableSpec({
        type: config.type,
        data: config.data,
        columns: config.columns,
        options: config.options || {},
        showLog: config.showLog
    });
    return jsonToDom({
        jsonSpec: spec,
        targetHtmlId: config.targetHtmlId,
        appendPosition: config.appendPosition,
        classToApply: config.classToApply ?? "",
        showLog: config.showLog
    });
};
Phase 2: Event Delegation Hooking
// src/v55/index.js
const hookEvents = (config = {}) => {
    const rootElement = typeof config.container === "string"
        ? document.getElementById(config.container)
        : config.container;

    const defaultRenderTable = (filteredRecords) => {
        // Re-renders the inner table content without
        // blowing away the outer search input container!
        render({
            data: filteredRecords,
            columns: config.columns,
            targetHtmlId: "table-content-container",
            appendPosition: "replace",
            type: "withFooter"
        });
    };

    return hookTableEvents({
        ...config,
        renderTable: config.renderTable || defaultRenderTable
    });
};
